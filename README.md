# 强提醒（Strong Reminder）

一个离线的中文 Mac 定时提醒工具。到点时覆盖所有已连接显示器，每两秒响一次系统提示音，直到点“我知道了”或“5 分钟后再提醒”。

## 功能

- 创建、查看和删除一次性提醒
- 全屏红色提示，支持多显示器
- 持续响铃和五分钟稍后提醒
- 可选的“登录时自动启动”
- 唤醒或重新打开应用时，检查一小时内错过的提醒

## 下载与使用

从 GitHub **Releases** 下载 `强提醒-Mac.dmg`，打开后把 `强提醒.app` 拖到“拖到这里安装”。打开应用，输入提醒内容和时间，点“添加提醒”。你可以点“预览全屏效果”确认屏幕和音量。

关闭主窗口后，应用仍在菜单栏运行；点击菜单栏的闹钟图标可重新打开。建议勾选“登录时自动启动”。若 macOS 要求批准，请到“系统设置 → 通用 → 登录项与扩展”允许。

此版本在本机临时签名，未经 Apple 公证。首次打开若被 macOS 拦截，可在“系统设置 → 隐私与安全性”中允许打开。

## 重要限制

应用退出或 Mac 关机时无法弹出提醒；Mac 睡眠时要等唤醒后才会检查。错过时间超过一小时的提醒会被清除。锁屏界面不能保证显示全屏提示。响铃使用系统提示音，音量取决于系统声音设置。若是绝不能错过的事项，建议同时设置手机闹钟。

## 隐私

提醒仅保存在本机 `~/Library/Application Support/强提醒/alarms.json`。应用不使用网络，也不读取日历。

## 从源码构建

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools。

```sh
./run-tests.sh
./build.sh
```

`build.sh` 会生成同时支持 Apple Silicon 和 Intel 的 `强提醒.app`。图标可用 `swift make-icon.swift AppIcon.png` 重新生成。
